# 모아트립 (MoaTrip) v1.4.0 🇹🇼

대만 여행의 Day 1~Day 4 일정, 지도, 주변 후보 장소, 카테고리별 핀을 친구와 함께 관리하는 반응형 웹앱입니다. 기존 v1.3.0의 공유 링크 및 여행 데이터 구조와 호환됩니다.

## v1.4.0 신규: 사진 속 글자 추출 (API 키 불필요)

- **📸 캡처 + 메모로 빠르게 추가**에서 아이폰/갤럭시 스크린샷(JPG·PNG 등)을 선택하면 **OCR이 자동 실행**됩니다.
- 브라우저 내 Tesseract.js를 이용해 **한국어·영어·대만 번체 중국어**를 읽습니다. **Gemini API 키나 Render 환경변수를 추가할 필요가 없습니다.**
- 추출된 글자를 **원문 그대로 확인 및 직접 수정**할 수 있습니다. 장소명으로 보이는 후보 버튼을 누르거나 제안된 상호명을 수정하여 검색할 수 있습니다.
- `짧은 메모`에 `셋째날 오후 3시, 쇼핑`처럼 입력하면 날짜·시간·카테고리를 해석하고, **정식 일정/⭐ 근처 후보**로 저장할 수 있습니다.
- 장소명은 OCR이 틀릴 수 있으므로 **검색 결과에서 위치를 확인하고 선택한 후** 일정에 추가합니다. 지도 좌표를 사진만 보고 추정하지 않습니다.
- **추출한 글자도 일정 메모에 첨부하기**는 선택 사항(기본 해제)입니다. 사진 파일 자체는 모아트립 서버로 보내지 않으며 일정 데이터에 보관하지 않습니다. 선택한 메모와 검색어/일정 입력값만 서버로 전송됩니다.
- 첫 OCR 이용 시 Tesseract.js 엔진과 언어 모델 파일을 외부 CDN에서 내려받습니다. **인터넷 연결이 필요**하며 아이폰 브라우저 종류·기기 메모리에 따라 시간이 걸리거나 실패할 수 있습니다. 실패하면 상호명을 직접 입력할 수 있습니다.
- OCR은 글자 추출 기술이지 AI 사진 이해 모델이 아닙니다. 블로그의 광고·게시 날짜나 주변 추천 장소까지 완벽하게 해석하지는 못합니다. 추출된 상호명과 일정 시간은 확인하세요.

## v1.3.0 업데이트: 대만 지도 지명을 한국어로

- 기존의 한자 지명이 이미지 안에 박힌 OpenStreetMap 래스터 배경 대신 **한국어 우선 벡터 지도**를 기본 적용했습니다.
- 기본 제공자는 Maptoolkit의 한국어 스타일 `summer-ko.json`이며 **별도 API 키 없이 작동**합니다. 지원되는 지명은 `타이베이`, `신베이`, `타오위안` 등 한국어로 표시됩니다.
- 두 벡터 지도에 `name_ko`/`name:ko` 우선 → 영어 → 현지어 순서의 레이블 표시 규칙을 적용합니다. Maptoolkit 연결에 실패하면 OpenFreeMap 벡터 지도로 자동 재시도합니다. 두 벡터 지도 모두 연결되지 않으면 기존 기본 지도로 복귀합니다.
- **한국어 번역이 없는 소규모 거리·가게는 영어 또는 현지 한자로 보일 수 있습니다.** 지도 업체의 이름 데이터가 없으면 모든 지명을 완전히 한국어로 바꿀 수는 없습니다.
- 기존 DAY 1~DAY 4, 방문 순서 핀, 카테고리 색상, ⭐ 근처 후보, 공유 및 장소 검색 기능은 유지했습니다.
- Maptoolkit 커뮤니티 지도 사용 조건에 따라 지도 왼쪽 아래 로고와 오른쪽 아래 지도 저작권 표시를 유지합니다.
- 사용 도중 지도 글자가 바로 안 바뀌면 Render가 새 버전을 배포했는지 확인하고 `Ctrl + Shift + R`로 캐시를 새로고침하세요.

## 기존 일정·지도·공유 기능 유지

- **사진 장소 자동 검색 흐름:** OCR이 추출한 장소명 후보를 확인하고 `지도에서 장소 찾아보기` 버튼을 누르면 위치 검색 결과를 표시합니다. 지역·날짜·시간은 `짧은 메모`를 우선합니다.
- **사진 없이도 빠른 입력:** 장소 이름과 날짜/시간 메모만으로 같은 일정 등록 기능을 사용할 수 있습니다.
- **시간순 동선:** 오전 8시/12시/18시 등 방문 시간순으로 자동 삽입합니다. `첫 방문` 표현이 있으면 우선 맨 앞으로 삽입합니다. 방문 시간이 없는 장소는 시간을 지정한 일정 이후에서 **직선거리 증가가 가장 적은 위치**를 선택합니다. 실제 도로 길찾기 최적화는 아닙니다.
- **카테고리 지도 핀:** 🔴 음식점·맛집 / 🔵 소품샵·마트·쇼핑 / 🟡 카페·디저트·간식 / 🟣 관광 / 🟢 숙소 / 회색 교통. 색상은 날짜가 아니라 장소 종류를 나타냅니다.
- **⭐ 근처 후보 장소:** 정식 일정과 별도 카드·테두리 핀으로 표시되며, 구글지도 길찾기 경유지와 동선 연결선에서 제외됩니다. 지도 하단 체크박스로 후보를 숨기거나 표시할 수 있습니다.
- **휴대폰 화면:** 상단에 지도, 하단에 DAY별 일정을 동시에 보는 화면을 기본 제공하고, 전체 지도 보기로 전환할 수 있습니다.
- 기존 친구 공유 URL, 실시간 편집(SSE), JSON/텍스트/ICS 내보내기, 수동 장소 검색과 지도 위치 선택을 유지합니다.

## 실제 입력 예시

블로그 화면을 캡처해서 사진을 고르고 아래와 같이 입력합니다.

> `7/23 셋째날 처음 갈 곳. 아침 8시쯤. 주먹밥 맛집. 근처에 총좌빙 맛집도 있다고 해요.`

자동 분석 내용: **DAY 3, 08:00, 맛집(빨간 핀), 첫 방문 순서**. 총좌빙 참고는 메모에 남깁니다. 날짜가 여행 기간과 일치하지 않는 경우에는 `셋째날`을 우선합니다. 검색된 장소 주소와 지도 위치는 저장 전 확인이 필요합니다.

근처 후보로 저장할 때는 `저장 유형`을 **⭐ 근처 후보**로 바꾸세요. 후보의 날짜·메모는 보관하지만 실제 동선에는 포함되지 않습니다.

## GitHub 저장소 업그레이드 (기존 Render 프로젝트 유지)

기존 저장소: `https://github.com/HyperEVMScan/taiwan-travel-app`

1. 이 ZIP을 **압축 해제**합니다.
2. GitHub의 기존 `taiwan-travel-app` 저장소에서 **Add file → Upload files**를 누릅니다.
3. 압축 해제 폴더 *안의* `server.js`, `package.json`, `public`, `locations`, 새 `lib`, `test`, `README.md` 등 전체를 선택해 업로드합니다. 기존 동일 경로 파일은 이번 버전으로 대체해야 합니다. ZIP 자체는 올리지 마세요.
4. **Commit changes**를 누릅니다.
5. Render의 기존 `taiwan-travel-app` 웹서비스에서 새 배포가 시작되는지 확인하고, 자동 배포가 시작되지 않으면 **Manual Deploy → Deploy latest commit**을 누르세요. 기존 `baseball-live-3leagues`에는 절대 올리지 마세요.
6. 새 기능이 보이지 않으면 휴대폰 브라우저에서 페이지를 새로고침하세요.

설정:
- Language: Node
- Branch: `main`
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/api/health`
- 기존 Render 웹서비스 이름·주소 유지

## 사진 글자 추출 설정

별도의 Render 환경변수 설정은 **없습니다.** Tesseract.js는 웹 브라우저 안에서 실행됩니다. `GEMINI_API_KEY`를 설정할 필요가 없습니다.

실제 사용할 때는 사진을 선택한 다음, `글자 추출 완료` 메시지와 `사진에서 추출한 글자` 칸을 확인하고 잘못 인식된 상호명을 수정하세요. 인식 결과를 메모에 남기고 싶으면 `추출한 글자도 일정 메모에 첨부하기`를 체크하세요.

정확한 장소 좌표는 앱의 장소 검색 결과에서 직접 선택해야 합니다. 사진 글자 인식과 지도 장소 검색은 서로 다른 기능이므로 검색 결과가 없을 수도 있습니다.

## 정확한 장소 검색(선택)

대만 현지 음식점이나 한자 상호명을 자주 검색한다면 `GOOGLE_PLACES_API_KEY` 연결을 권장합니다. 이는 **사진 인식 키와 별개**입니다.

1. Google Cloud에서 Places API (New)를 활성화합니다.
2. Render Environment에 `GOOGLE_PLACES_API_KEY`를 추가합니다.
3. Google Cloud에서 API 키 제한·청구 한도를 관리하세요. Places API (New) 사용량에 따라 비용이 발생할 수 있습니다.

설정하지 않아도 앱 내장 대만 주요 관광지 및 OpenStreetMap 검색은 작동합니다. 다만 **작은 식당, 현지 별칭, 블로그 속 가게는 검색되지 않을 수 있습니다.** 인식된 상호명을 수정해 재검색하거나 지도에서 직접 위치를 찍어 추가할 수 있습니다.

## 영구 저장 (꼭 확인)

기본 저장소는 `data/`의 로컬 JSON입니다. Render 무료 웹서비스에서는 **재배포·재시작 시 이 파일이 유실될 수 있습니다.** 링크 공유와 실시간 편집이 되더라도 영구 보존을 보장하지 않습니다.

장기간 사용할 여행 일정은 Render Environment에 별도 Turso DB 연결을 권장합니다.

```env
TURSO_DATABASE_URL=libsql://your-database.turso.io
TURSO_AUTH_TOKEN=your-database-token
```

기존 로컬 JSON 데이터가 **Turso로 자동 이전되지는 않습니다**. 변경 전에 현재 여행을 `여행 내보내기 → JSON 파일`로 백업하고, DB 연결 후 앱 `JSON 여행 가져오기` 기능으로 복원하세요. 복원된 여행은 **새 링크 ID**로 생성되므로 친구에게 새 링크를 공유해야 합니다.

## 개발 및 테스트

Node.js 20 이상. 외부 Node npm 라이브러리 없이 실행됩니다.

```cmd
npm install
npm run verify
npm start
```

URL: `http://localhost:3000` / 상태 확인: `/api/health`

프로젝트 구조:

```text
server.js                  백엔드/지도검색/동시편집
lib/quick-add.js           날짜·시간·카테고리 파싱/동선 자동 삽입
package.json               Node 실행·테스트 설정
public/index.html          웹화면
public/app.js              사진·메모 빠른 추가/일정/지도/공유
public/ocr.js              브라우저 OCR (한국어·영어·번체 중국어)
public/style.css           PC·모바일 스타일
public/icon.svg            아이콘
public/manifest.webmanifest
locations/taiwan.json      기본 대만 장소 목록
data/.gitkeep              로컬 저장소 (JSON 데이터는 Git에 포함하지 않음)
test/server.test.js        서버 자동 테스트
test/ocr.test.js           OCR 문자열 후보 분석/연동 구조 테스트
render.yaml                Render 배포 설정
```

**테스트 범위:** 서버와 OCR 텍스트 분석 자동 테스트 27개 통과. Chromium 모바일(390×844) UI 스모크 테스트에서 사진 첨부→가짜 OCR 결과 표시→지도 장소 검색→DAY 3 저장까지 확인. 실제 Tesseract.js CDN 언어 파일 다운로드, 대만 여행 블로그 사진의 인식률, 실제 아이폰·갤럭시 동작은 이 실행 환경에서 검증하지 못했습니다.
